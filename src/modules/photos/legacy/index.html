Горизонтальные примеры

Один и тот же 4:3 кадр через разные горизонтальные crop-окна.
4:3полный кадр
Виден весь итоговый кадр.
1:1crop по бокам
Фото не сжимается. Квадратное окно просто скрывает левую и правую часть.
3:2crop сверху/снизу
Тот же масштаб. Часть верха и низа скрывается маской.
16:9wide crop
Широкое окно сильнее отсекает верхнюю и нижнюю часть кадра.

Вертикальные примеры

Тот же 4:3 кадр без изменения масштаба автомобиля, но через вертикальные окна.
3:4вертикальный crop
Обрезается большая часть боков, центральный объект остаётся в исходном масштабе.
4:5портретное окно
Более узкое вертикальное окно. Полезно видеть, насколько быстро исчезают края автомобиля.
2:3сильный portrait crop
Сильнее режет бока. Хороший стресс-тест для центральной композиции.
9:16максимальный вертикальный crop
Самый жёсткий вертикальный тест: остаётся только центральная колонка исходного 4:3 кадра.
Во всех восьми окнах лежит один и тот же собранный 4:3 кадр. Размер автомобиля внутри него не меняется. Различается только форма маски, которая скрывает лишние области. Фирменные цвета, карточки, тени и красные акценты относятся только к интерфейсу редактора и не попадают в экспортируемый JPG.
