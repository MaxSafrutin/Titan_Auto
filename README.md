# TITAN AUTO

Единая web-платформа автосалона: внутренний CRM/ERP-портал и публичный каталог автомобилей.

- Frontend: статический Vanilla JS, готовый для GitHub Pages.
- Backend: Google Apps Script Web App.
- Данные: Google Sheets.
- Файлы: Google Drive.
- Локальный сервер не требуется.

Начните с [архитектуры](docs/ARCHITECTURE.md) и [пошаговой установки](docs/DEPLOYMENT.md).

Исходные рабочие приложения не изменены и пока остаются legacy. Их подключение выполняется последовательно через TitanAPI adapters.
