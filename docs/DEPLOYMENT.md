# Развёртывание TITAN AUTO

## Первая установка

Ни локальный сервер, ни Node.js, ни Docker не нужны. Используются уже созданные ресурсы:

- Google Sheet ID: `1SqiNTZTBZkr1GyO6Nj3yU3S_YhjjmAR6AEwI5KKPMoM`
- Drive root folder ID: `1PrA1wvGulGZ8S5R72gY5rKReOFdM_xNp`
- GitHub: `https://github.com/MaxSafrutin/Titan_Auto`

### 1. Создайте Apps Script

1. Откройте [таблицу Titan Auto Data](https://docs.google.com/spreadsheets/d/1SqiNTZTBZkr1GyO6Nj3yU3S_YhjjmAR6AEwI5KKPMoM/edit).
2. В верхнем меню нажмите **Расширения → Apps Script**.
3. Назовите проект `TITAN AUTO API`.
4. Удалите только пустой пример `myFunction` из `Code.gs`.
5. Для каждого файла из папки `backend/apps-script` нажмите слева **+ → Скрипт**, создайте файл с тем же именем и вставьте его содержимое. Расширение `.gs` в поле имени можно не писать.
6. Откройте **Настройки проекта**, включите показ файла манифеста и замените его содержимым `appsscript.json`.

### 2. Подключите таблицу и Drive

1. Вернитесь в редактор кода.
2. В верхней панели выберите функцию `configureProject`.
3. Для первого запуска удобнее временно добавьте в самый низ `Setup.gs`:

```javascript
function firstInstall() {
  configureProject(
    '1SqiNTZTBZkr1GyO6Nj3yU3S_YhjjmAR6AEwI5KKPMoM',
    '1PrA1wvGulGZ8S5R72gY5rKReOFdM_xNp',
    'https://maxsafrutin.github.io'
  );
  setAdminPassword('ЗАМЕНИТЕ_НА_СВОЙ_PIN');
  return setupProject();
}
```

4. Замените `ЗАМЕНИТЕ_НА_СВОЙ_PIN` на PIN длиной минимум 4 символа.
5. Выберите `firstInstall` и нажмите **Выполнить**.
6. Google попросит доступ к таблице и Drive: выберите свой аккаунт, нажмите **Дополнительные настройки → Перейти на страницу “TITAN AUTO API” → Разрешить**.
7. Дождитесь результата с `ok: true`. В таблице появятся новые листы, а в Drive — папки `VEHICLES`, `BACKUPS`, `EXPORTS`. Старый лист `CRM-Sales-Titan Auto` останется на месте.
8. Удалите функцию `firstInstall` из `Setup.gs`, чтобы PIN не оставался в исходном коде, и сохраните проект.

Если адрес GitHub Pages будет другим, укажите его вместо `https://maxsafrutin.github.io`. Для временной проверки допустимо передать `'*'`, а после проверки заменить на точный origin повторным `configureProject(...)`.

### 3. Опубликуйте API

1. Нажмите справа вверху **Начать развёртывание → Новое развёртывание**.
2. Нажмите значок шестерёнки и выберите **Веб-приложение**.
3. Описание: `TITAN AUTO API v1`.
4. **Запуск от имени:** `Я`.
5. **У кого есть доступ:** `Все`.
6. Нажмите **Начать развёртывание**, подтвердите доступ.
7. Скопируйте URL, заканчивающийся на `/exec`. URL `/dev` использовать нельзя.

Доступ «Все» нужен, потому что собственная авторизация проверяется backend-сессией, а публичный каталог должен открываться без Google-входа. Таблица и файлы при этом не становятся публичными.

### 4. Подключите frontend

1. Откройте опубликованную страницу TITAN AUTO.
2. Вставьте `/exec` URL в поле подключения.
3. Нажмите **Подключить**.
4. Введите созданный PIN.

API URL не является секретом и хранится только в `localStorage` браузера. PIN и секреты там не хранятся.

### 5. Включите GitHub Pages

1. Откройте репозиторий `MaxSafrutin/Titan_Auto` на GitHub.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
5. После появления адреса откройте его и выполните шаг 4 выше.

## Проверка после установки

1. Войдите и создайте тестовый Kia Rio.
2. Убедитесь, что ID имеет вид `TA-000001`, а строка появилась в `VEHICLES`.
3. Откройте карточку, измените цену и обновите страницу.
4. Добавьте контакт и оценку; проверьте `CONTACTS`, `VALUATIONS`, `AUDIT_LOG`.
5. Загрузите небольшое фото; проверьте превью/скачивание в приложении и папку `VEHICLES/TA-000001/photos` в Drive.
6. После проверки архивируйте тестовую запись или используйте отдельную `createDemoData()` только если тестовые данные действительно нужны.

## Обновление backend

После изменения `.gs` файлов вставьте обновления в Apps Script, затем **Начать развёртывание → Управление развёртываниями → карандаш → Новая версия → Начать развёртывание**. URL `/exec` останется прежним.

## Резервная копия

В редакторе Apps Script выберите `createBackup` и нажмите **Выполнить**. Копия таблицы с датой появится в `BACKUPS`. Автоматическое расписание можно добавить позже через раздел **Триггеры**.
