## Что найдено

Целевой репозиторий `Titan_Auto` был пуст. Исходные рабочие приложения находятся рядом и остаются неизменными.

| Источник | Текущая технология | Важные данные/функции | Целевой модуль | Статус миграции |
|---|---|---|---|---|
| Генератор документов | React + TypeScript + Vite, IndexedDB, DOCX/ZIP | сделки, контрагенты, ПТС/СТС, шаблоны документов | `documents` + `deals` | legacy, подключать после ядра |
| Генератор общих сторис | HTML/CSS/JS, Canvas, JSON | фото, характеристики, цена, готовые серии | `stories` | legacy |
| Генератор ценников | HTML/CSS/JS, QR, JSON | характеристики, цена, комплектация, PDF/печать | `price-tags` | первый кандидат для адаптера |
| Дизайн-код ТИТАН АВТО | бренд-гайд и логотипы | цвета, шрифты, тон, официальный SVG | общие стили/ассеты | логотип скопирован, токены применены |
| Калькулятор оплаты | HTML/CSS/JS, JSON | сделки, маржа, кредитная комиссия, выплаты, фактические расчёты | `payments` + `analytics` | legacy |
| Лендинг-визитка | статический HTML и медиа | публичное представление компании | `catalog/public` | legacy; позднее объединить с каталогом |
| Навигатор звонка | HTML/JS, JSON | лид, контекст звонка, следующий контакт, встреча, сообщения | `calls` + `leads` | legacy |
| Оценка автомобилей | HTML/CSS/JS, IndexedDB, Canvas, печать | акт, диагностика, рынок, вложения, предложения | `valuation` | legacy |
| Редактор загрузки фото | единый HTML | кадрирование фото для объявлений | `photos` | legacy |

В Google Drive обнаружена корневая папка с существующей таблицей `Titan Auto Data`. Таблица содержит один пустой лист `CRM-Sales-Titan Auto`; существующие записи в нём отсутствуют. Ядро не удаляет этот лист: `setupProject()` создаёт рядом нормализованные листы.

## Целевая схема

```text
GitHub Pages (App Shell: внутренний портал + публичный каталог)
                        |
                        v
              TitanAPI (единственный fetch)
                        |
                        v
          Google Apps Script Web App / Router
                        |
             Services + Repository layer
                 /                 \
                v                   v
       Google Sheets            Google Drive
       structured data          binary files
```

Google Sheets и Drive заменяемы: frontend знает только контракт TitanAPI, а бизнес-операции не зависят от API таблиц.

## Границы первой версии

Ядро включает авторизацию, dashboard, автомобили, лиды, контакты, оценки, задачи, продажи, файлы, аудит и публичный каталог. Генератор ценников подключён первым адаптером: он работает внутри App Shell и получает общие данные выбранного автомобиля без повторного ввода. Сторис, документы, акт оценки, навигатор звонка, редактор фото и расчёт выплат пока остаются legacy до подключения следующими адаптерами.

## Правила интеграции legacy

1. Общие поля читаются из `TitanAPI.vehicles.get(vehicleId)`.
2. Специфические поля модуля сохраняются в нормализованных таблицах либо в `payload_json`, пока схема не стабилизирована.
3. Сгенерированный результат загружается через `TitanAPI.files.upload()` и связывается с `vehicle_id`.
4. Рабочий алгоритм генератора не переписывается без отдельной причины.
5. Исходные папки никогда не становятся runtime-зависимостью опубликованного приложения.

## Два уровня продукта

- Внутренний портал: данные продавцов, закупочные цены, контакты, оценки, задачи, аудит и аналитика. Требует сессию.
- Публичный каталог: только опубликованные автомобили и разрешённые поля. Работает по `#/catalog` без сессии.

Публикация автомобиля наружу управляется полем `public_status`; приватные поля никогда не возвращаются публичным endpoint.
